Overview

What is GroupFun?

GroupFun is an existing dating platform. The original event page provided only basic event information, such as the event description and venue. The goal of this project was to expand the event experience with social interactions, event participation features and a more personalized user profile.

The Challenge

Original design

  • Basic event description
  • Venue information
  • No social interactions
  • No way to express interest or confirm attendance
  • No clear connection between events and user profiles

Design goal

The goal was to transform a static event page into an interactive experience where users could engage with events, connect with other members and manage their social activities.

Original event page — static, with no participation or social features.

Event Page Redesign

The New Event Experience

The redesigned event page transforms a static information screen into a fully interactive experience. Users can now engage socially, confirm their attendance, and see who else is joining — all within a single cohesive layout.

Redesigned event page — all key interactions in a single view.
Key Functionalities
  • Social interactions — Like and Share actions let users engage with events and spread them within their network.
  • Event engagement — Dedicated Interested and Attend actions give users two levels of commitment, reducing friction to participation.
  • Attendance overview — The number of people attending is displayed prominently, adding social proof and encouraging others to join.
  • Empty state — When no one has joined yet, users see a "Join Event" button with the message "Be the first one there!" — turning an empty state into a call to action.
  • Attendance confirmation — A confirmation modal appears before joining, preventing accidental sign-ups and setting clear expectations.
  • Authentication — Unauthenticated users are shown a login/register prompt when they attempt to interact, keeping the flow uninterrupted.

Event Page Redesign

From Information Dump to Editorial Clarity

The event detail page was the most-visited screen in the app and the primary source of user frustration. A before/after comparison shows the shift from a dense, undifferentiated layout to a scannable editorial hierarchy where the most important information is immediately visible.

Before
After
Key Design Decisions
  • Hero image first — large visual immediately sets context before any text.
  • Sticky CTA bar — RSVP button remains accessible as the user scrolls through event details.
  • Progressive disclosure — essential details (date, location, host) up top; secondary info collapsed into expandable sections.
  • Social proof surface — attendee avatars and group count shown prominently to encourage participation.
New User Profile

A Central Place for Social Activity

The new profile page gives users a central place to explore their social activity, see their friends and keep track of events they are attending.

New profile page — events, friends and social activity in one place.
Profile Features
  • User's events and activities — a feed of events the user has interacted with, liked or shared.
  • Friends — a list of connections with quick access to their profiles and shared events.
  • Events the user is attending — a dedicated section showing upcoming and past events the user has confirmed attendance for.
Final Design & Outcome

From Static Page to Interactive Experience

The redesign expanded the original static event page into a more interactive experience. Users can now engage with events, express interest, confirm attendance and connect their event activity with their personal profiles.
